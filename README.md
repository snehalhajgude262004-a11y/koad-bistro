# Koad Bistro

A responsive restaurant website built with **React, Vite and Bootstrap**.

## Highlights

- Responsive desktop, tablet and mobile layouts
- Reusable React components for menu, services, reviews, news and footer sections
- Mobile off-canvas navigation
- Interactive reservation form with client-side validation and confirmation feedback
- Simple add-to-order interaction with a live item counter
- Smooth section navigation and accessible labels/alt text

## Tech Stack

- React 19
- Vite
- Bootstrap 5
- Bootstrap Icons
- CSS3
- JavaScript (ES6+)

## Run Locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Portfolio Note

This repository represents a customized version of the restaurant website. The UI, interactive reservation flow, navigation behavior, order interaction, content and documentation were customized for portfolio development.
